# 光線法手簿教學模擬器

只要輸入每個點的正確水平角與距離（天頂角、儀器高、稜鏡高可留空自動產生），就能產生外業光線法手簿的教學模擬資料：正倒鏡讀數、兩次測距、已知點檢核誤差，以及補點（暫時性控制點）清單。

手簿頁尾及列印時每頁底部都會標示「本手簿之正倒鏡讀數與測距為程式依輸入值模擬產生，非實測紀錄」，供教學與練習使用。

## 線上使用

直接開啟：https://gn01918004-hub.github.io/handbook/

## 離線使用

整個工具只有一個檔案 `index.html`，不需要安裝。

1. 下載 `index.html`（或整個專案 ZIP：Code → Download ZIP）。
2. 用 Chrome、Edge 或 Firefox 開啟。
3. 可直接把 `index.html` 寄給學生、放到雲端硬碟或教學平台。

離線也能使用，只是字型會改用系統內建字型。

## 功能

- **表頭**：工程名稱、日期、天氣、起訖時間、使用儀器與序號、溫度／氣壓、觀測者、記簿者。儀器預設為全測站經緯儀 Nikon XS（E131502），可用「＋ 新增儀器」增加。
- **測站**：每站設一個後視點、一個檢核點（第三控制點），再加入放樣點或補點。
- **點的類別**：點號 `Q` 開頭自動設為補點，全數字自動設為放樣點。
- **正倒鏡模擬**：每鏡讀數偏離正確值不超過設定上限（0–60″），正倒鏡平均等於輸入值；同時算出 2C 與天頂角指標差。
- **兩次測距**：每次偏差不超過設定上限（≤ 0.020 m），平均等於輸入距離。
- **已知點檢核**：後視與檢核點加入小偏差，在最後一欄記錄較正確值差（例：`+0.012`），超過容許值時標示。
- **補點清單**：列出每個補點的測設測站、後視、平均觀測值與後續使用情形；補點在測設前就被使用時會提示。
- **亂數種子**：種子相同就產生相同數據，方便出題與對答案。
- **輸出**：「列印手簿」（A4 橫式）或「複製手簿」貼到 Excel；輸入內容可用 JSON 匯出／匯入。

## 角度輸入格式

`47.1836`（度.分秒）、`47 18 36`、`47°18'36"` 皆可，取至 1″。
